# Contributing to the public platform

Thank you for helping build the ALPHA PROXIMA public presence.

1. Work on a feature branch, not on `main`.
2. Submit a pull request with the proposed change and a completed [publication gate](docs/CONTENT-APPROVAL.md).
3. Run `python3 scripts/check_public_safety.py` and `python3 -m unittest discover -s tests -v`.
4. Explain whether the change affects privacy, accessibility, internationalization or deployment.
5. Wait for Founder approval; **do not** merge without it.

Do not submit material copied from the private Core or reuse its Git history. Do not submit unreviewed assets, memory, personal information, credentials or unpublished institutional mandates.
