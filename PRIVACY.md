# Privacy

ALPHA PROXIMA ONE v0.1 stores captures, goals, projects, tasks, preferences and journal entries in the current browser on the current device. The application has no account, backend, analytics, telemetry, or AI connection. It does not transmit entered content by design. The UI and application assets are served by whichever host you choose; hosting providers may process ordinary web request metadata.

Exported backups are portable JSON and are not encrypted. Store them carefully. Import replaces all current application data after confirmation. Clearing browser data or changing browser profiles/devices may remove or hide local records; export backups regularly. Future synchronization is not available in v0.1.
