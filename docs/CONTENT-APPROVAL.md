# Founder Publication Gate · Public Repository

**Status of this template:** proposed for public repository workflow only; not a ratification of any private charter.

Before publishing any update, the reviewer checks and records:

- [ ] Information is explicitly intended for unrestricted public visibility.
- [ ] No files, excerpts or knowledge exports from `Omi/`, `12_PEOPLE/`, `13_OPERATIONS/`, `03_AI_COUNCIL/`, `04_DECISIONS/`, `06_GOVERNANCE/`, `09_OFFICES/` or other private Vault paths.
- [ ] No customer data, full names from internal records, addresses, health details, emails, phone numbers, internal schedules, credentials or sensitive plans.
- [ ] No Git submodules, subtree merges or history imports from the private Core.
- [ ] No implicit claims that conceptual agents are deployed, conscious, independently authorized, or formally appointed.
- [ ] No unverified health, financial, or metaphysical claims presented as proven science.
- [ ] No third-party images or brand assets without permission.
- [ ] CI checks passed and secrets were not exposed in PR comments or CI logs.
- [ ] Release reviewed and **explicitly approved by the Founder**.

**Suggested PR note:**

```text
PUBLICATION GATE
Scope:
Sanitized content source:
Private information excluded:
CI status:
Human reviewer:
Founder approval:
Deployment target:
```

Do not publish if any box is unchecked. Do not copy private source material into the PR to request approval.
